## 📋 About the Project

This project simulates the complete flow of an online store, from product listing to order tracking, with a focus on practicing application logic, DOM manipulation, and automated testing.

## ✨ Features

- 🛍️ Product listing
- 🔍 Product search
- 🛒 Shopping cart
- 💳 Checkout
- 📦 Order creation
- 📋 Order management
- 🚚 Order tracking
- 🔄 Product updates
- 📅 Delivery date calculation
- 🔗 URL parameters
- ✅ Automated tests with Jasmine

## 🛠️ Technologies

| Technology | Purpose |
|---|---|
| **HTML5** | Page structure |
| **CSS3** | Styling and layout |
| **JavaScript** | Application logic |
| **Jasmine** | Automated testing |

## 🔄 Application Flow

```
Products → Shopping Cart → Checkout → Order → Order Tracking
```

## 🧪 Testing

The project uses **Jasmine** for automated testing of the JavaScript application logic, ensuring greater reliability in the implemented features.
